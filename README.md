# GoogleDriveClone

A simplified Google Drive clone built using **ASP.NET Core MVC**. This project allows users to register, log in, create folders, upload files, and manage them in a user-friendly interface that mimics Google Drive.

---

## 🚀 Features

- ✅ User authentication (login/logout)
- 📁 Folder creation and nested folder navigation
- 📂 File upload with thumbnail preview
- 🗑️ Delete folders/files
- 📄 Display file types with default or generated thumbnails
- 📌 Navigation bar showing current folder path
- 📤 File download and viewing
- 🧾 PDF generation support using DinkToPdf

---

## 🛠️ Technologies Used

- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- SQL Server / LocalDB
- DinkToPdf (for PDF export)
- Bootstrap (for styling)
- Cookie-based Authentication
